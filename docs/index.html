Pipeline architecture

The repository was refactored to behave like a compact analytical application with a package, script wrapper, tests, and a dashboard contract.

1
Source dataset ingestion
Load heart records and split train/test with stratification.
2
Preprocessing pipeline
Scale numeric columns and one-hot encode categorical variables.
3
Dual-model evaluation
Benchmark Logistic Regression and Random Forest on the same holdout split.
4
Analytical export layer
Write model, quality, rate, calibration, threshold, confusion, and metadata files.
5
Dashboard contract tests
Validate that the pipeline reproduces the artifacts consumed by the front end.
